# MAILCHECK — сайт подтверждения почты

## Запуск локально
1. Установите Node.js 18 или новее.
2. В папке проекта выполните `npm install`.
3. Скопируйте `.env.example` в `.env`.
4. Заполните SMTP-настройки вашего почтового провайдера и задайте длинный случайный `OTP_SECRET` (не менее 32 символов).
5. Выполните `npm start` и откройте `http://localhost:3000`.

## Важно
- Код отправляется на введённый адрес и не показывается в браузере: иначе проверка теряет смысл.
- Не публикуйте `.env`, SMTP-пароль или `OTP_SECRET`.
- Сейчас коды хранятся в памяти процесса и исчезают при перезапуске. Для публичного production-сайта замените Map на Redis/БД, добавьте HTTPS, CSRF-защиту при использовании cookie-сессий, мониторинг и политику хранения данных.
- Настройте SPF, DKIM и DMARC для домена отправителя, чтобы повысить доставляемость.
- Не используйте личный пароль от обычной почты как SMTP-пароль; используйте отдельные SMTP-учётные данные или пароль приложения, если провайдер это поддерживает.
